# HomeNode

HomeNode — домашняя медиатека и управление загрузками на роутере с OpenWrt и USB SSD. Сервер написан на Go; веб-интерфейс встроен в один исполняемый файл и открывается с компьютера или телефона.

Проект находится в стадии работающего прототипа. Пути, сетевые адреса и OpenWrt-скрипты нужно адаптировать к своему роутеру. Автоматического установщика пока нет.

## Возможности

- Медиатека для аниме, фильмов и музыки; видео можно смотреть в браузере или через VLC по SMB.
- Список серий, история просмотра, продолжение с сохранённой позиции и переход к следующей серии.
- Поиск AniLiberty и RuTracker, добавление выбранной раздачи в Transmission.
- Управление загрузками: запуск, пауза и отдельные действия для удаления задачи или задачи вместе с файлами.
- Необязательный Telegram-бот с привязкой владельца и уведомлениями о завершении загрузки.
- Три режима маршрутизации устройства: обычный интернет, VPN для выбранных сервисов и весь трафик через VPN.
- Состояние VPN и SSD, ежедневные копии SQLite. Для iPhone предусмотрена установка сайта на экран «Домой».

## Что потребуется

- Роутер с OpenWrt и подключённым SSD, смонтированным в `/mnt/ssd`, либо собственные пути в конфигурации.
- Transmission с включённым RPC и отдельными учётными данными.
- Go 1.25 или новее на компьютере, где собирается сервис.
- `ffmpeg` на роутере, если нужно воспроизводить MKV в Safari. `smartctl` нужен для показателей SSD.
- Samba для доступа к файлам через VLC; исходящий VPN и Tailscale необязательны.

## Сборка и запуск

Проверить код и собрать бинарный файл для роутера ARM64:

```sh
go test ./services/home-api/...
go vet ./services/home-api/...
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags='-s -w' \
  -o homenode-api-linux-arm64 ./services/home-api/cmd/homenode-api
```

Для другой архитектуры измените `GOARCH`. Скопируйте бинарный файл на роутер и подготовьте закрытый `/etc/homenode.env` по образцу [`homenode.env.example`](services/home-api/deploy/homenode.env.example). Обязательные значения:

- `HOMENODE_USER`, `HOMENODE_PASSWORD` — отдельный вход в HomeNode;
- `HOMENODE_SESSION_SECRET` — случайная строка длиной не менее 32 символов;
- `TRANSMISSION_RPC_USERNAME`, `TRANSMISSION_RPC_PASSWORD` — доступ к Transmission RPC.

Файл окружения должен быть доступен только администратору (`chmod 600 /etc/homenode.env`). Не копируйте реальные значения в репозиторий. Пример OpenWrt-службы находится в [`homenode.init`](services/home-api/deploy/homenode.init): перед установкой проверьте пользователя `homenode`, группу `transmission`, пути к SSD и адрес RPC. По умолчанию веб-интерфейс слушает порт `8787`; `/health` отвечает без входа.

## VPN и удалённый доступ

Скрипты в [`scripts/`](scripts/) и списки в [`services/home-api/deploy/`](services/home-api/deploy/) показывают пример выборочной маршрутизации через AmneziaWG. Для её настройки нужны собственный VPN-профиль, адрес интерфейса в `VPN_BIND_ADDRESS`, подходящие правила firewall и DNS роутера. Скрипты меняют сетевые настройки OpenWrt: прочитайте их и сохраните текущую конфигурацию перед запуском.

Для удалённого открытия сайта можно настроить Tailscale Serve с HTTPS внутри своей tailnet. HomeNode требует вход и при таком подключении. Не публикуйте порт `8787`, Transmission RPC или Samba напрямую в интернете.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `services/home-api/cmd/homenode-api` | запуск Go-сервера |
| `services/home-api/internal/server` | HTTP API, авторизация и медиапотоки |
| `services/home-api/internal/store` | SQLite и история просмотра |
| `services/home-api/internal/webui` | интерфейс, встроенный в бинарный файл |
| `services/home-api/internal/{aniliberty,rutracker,transmission,telegram}` | интеграции |
| `services/home-api/deploy` | шаблон настроек и службы OpenWrt |
| `scripts` | необязательные сетевые скрипты |

В репозитории нет медиафайлов, учётных данных, VPN-профилей, баз данных, журналов или резервных копий устройства. Поиск RuTracker зависит от его веб-страниц и может потребовать адаптации при изменении сайта.
