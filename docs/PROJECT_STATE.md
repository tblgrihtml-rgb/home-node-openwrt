# Состояние проекта

## Готово

- Go API, встроенный веб-интерфейс, медиатека, загрузки Transmission и привязанный Telegram-бот.
- Музыка из Windows-каталога владельца перенесена напрямую на SSD роутера через локальную сеть: из 911 FLAC/M4A-файлов 746 добавлены и 165 точных дублей пропущены по SHA-256. В каталоге медиатеки после импорта 1258 настоящих аудиофайлов, временных `.part` нет. Источник на Windows не изменён.
- Временный импорт музыки от владельца бота: файл сохраняется на SSD в `music/Исполнитель/Альбом`, дубликат с тем же Telegram ID повторно не скачивается.
- В боте есть `/music`, список треков и действия «Слушать»/«Скачать»; на сайте музыкальные файлы можно воспроизвести и скачать.
- На сайте музыка выделена в собственную вкладку с поиском по исполнителю, альбому и треку; прежняя «Медиатека» переименована в «Видео» и показывает только фильмы/сериалы. Интерфейс развёрнут на роутере; сами файлы при этом не перемещались.
- Панель устройств объединяет DHCP-аренды и обнаруженных соседей LAN: устройства со статическим IP также видны. Полный VPN помечает IPv4-трафик выбранного MAC-адреса на входе в роутер и поэтому не зависит от DHCP-аренды. Изменение установлено на роутере и проверено по списку устройств, VPN-набору и маршруту.
- Видеоплеер на широком экране имеет ambient-подсветку от четырёх краёв текущего кадра, включая боковые области; симметричные чёрные полосы, закодированные в видео, закрываются цветом соответствующих краёв. Есть отдельная кнопка полноэкранного режима с подсветкой и выключатель эффекта. Компоновка на телефоне переносит серии под видео. Изменение развёрнуто на роутере и проверено в браузере по локальной сети.

## Ограничения и известные вопросы

- Обычный Telegram Bot API позволяет скачать файл до 20 МБ. Для больших файлов подготовлен временный локальный API-сервер на Mac с файловым каталогом на SSD через SMB и SSH-туннелем для запросов роутера. Пока это не развёрнуто и не проверено с реальным файлом.
- Если `ffprobe` недоступен или в файле нет тегов, исполнитель/альбом могут попасть в «Неизвестный исполнитель»/«Без альбома».
- Тесты кода проходят, но работа с реальным ботом и роутером должна быть проверена после развёртывания.
- Функция импорта временная и может быть удалена отдельно; уже сохранённые музыкальные файлы при этом удаляться не должны.
- Импорт Windows не зависит от Telegram API ID/hash. Автоматическое получение файлов больше 20 МБ, присылаемых боту, по-прежнему ждёт развёртывания локального Bot API.
- Спящий или не обменивавшийся трафиком клиент без DHCP-аренды может не появиться до первого обращения к роутеру; пассивное обнаружение не является полным сканированием сети.
- Динамическая подсветка — эффект браузера, а не обработка файлов на роутере. При запрете чтения кадра или выключении эффекта остаётся статический тёмный фон; исходное видео не обрезается. Работа на iPhone/Safari и через Tailscale пока не проверена. Обнаружение встроенных чёрных полос эвристическое: очень тёмная сцена может временно выглядеть как полоса.
- На компьютере штатная кнопка полноэкранного режима внутри `<video>` скрывается, если доступен полноэкранный режим HomeNode: штатная кнопка разворачивала только видео и оставляла чёрные поля без подсветки. Используется «На весь экран» над видео. На телефоне и в браузере без Fullscreen API штатная кнопка остаётся.
