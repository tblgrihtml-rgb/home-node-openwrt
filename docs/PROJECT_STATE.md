# Состояние проекта

## Готово

- Добавлены и установлены на роутер поиск отдельных музыкальных треков, браузерная проверка доступа к стороннему источнику и SQLite-очередь FLAC с общей паузой после временной недоступности. Загрузчик ограничен одним заданием и записью только на смонтированный SSD. Поиск и интерфейс проверены 2026-10-18; реальное скачивание ещё ждёт подтверждения источника владельцем и одного тестового трека.

- Go API, встроенный веб-интерфейс, медиатека, загрузки Transmission и привязанный Telegram-бот.
- Музыка из Windows-каталога владельца перенесена напрямую на SSD роутера через локальную сеть: из 911 FLAC/M4A-файлов 746 добавлены и 165 точных дублей пропущены по SHA-256. В каталоге медиатеки после импорта 1258 настоящих аудиофайлов, временных `.part` нет. Источник на Windows не изменён.
- Временный импорт музыки от владельца бота: файл сохраняется на SSD в `music/Исполнитель/Альбом`, дубликат с тем же Telegram ID повторно не скачивается.
- Telegram-бот раз в сутки сверяет уже сохранённые тайтлы в `anime/` с сериями AniLiberty. Новую серию добавляет в Transmission и сообщает об этом; состояние хранится в SQLite, стартовая проверка не рассылает старые серии.
- Уведомления о новых сериях развёрнуты на роутере 2026-10-15; проверено сопоставление всех 3 аниме из медиатеки и ответ AniLiberty API с сериями.
- В боте есть `/music`, список треков и действия «Слушать»/«Скачать»; на сайте музыкальные файлы можно воспроизвести и скачать.
- Уведомления бота о проблемах загрузки теперь отправляются только для локальных ошибок Transmission (например, нехватка места или прав на запись), а не для повторяющихся предупреждений трекера. Для локальной ошибки бот уведомляет один раз до её сброса.
- На сайте музыка выделена в собственную вкладку с поиском по исполнителю, альбому и треку; прежняя «Медиатека» переименована в «Видео» и показывает только фильмы/сериалы. Интерфейс развёрнут на роутере; сами файлы при этом не перемещались.
- Панель устройств объединяет DHCP-аренды и обнаруженных соседей LAN: устройства со статическим IP также видны. Полный VPN помечает IPv4-трафик выбранного MAC-адреса на входе в роутер и поэтому не зависит от DHCP-аренды. Изменение установлено на роутере и проверено по списку устройств, VPN-набору и маршруту.
- Видеоплеер возвращён к прежнему виду без ambient-подсветки по просьбе владельца. Потоковое видео, сохранение позиции и список серий остались.
- Добавлена и развёрнута отдельная вкладка «Манга» для EPUB-книг с изображениями: полноэкранная читалка, управление страницами, направление справа налево, подгонка по высоте/ширине, светлый/тёмный фон и синхронизация номера страницы через SQLite. Каталог хранения — `/mnt/ssd/media/manga`; книги туда добавляются через SMB. Проверенная книга содержит 2787 страниц.
- Фильм Spider-Man Brand New Day разложен в `movies/Spider-Man Brand New Day (2026)`; его торрент остался зарегистрирован в Transmission. Книга My Dress-Up Darling перенесена в каталог манги, прогресс чтения сохранён.

## Ограничения и известные вопросы

- SpotiFLAC Community, Songlink и каталог поиска — внешние сервисы без гарантии доступности. Внешний сервис не принимает callback на адрес роутера: после проверки нужно вставить адрес `127.0.0.1` с одноразовым `grant` в HomeNode. В Chrome внешний виджет Cloudflare пока не появился, поэтому реальная загрузка FLAC не подтверждена. Браузерное подтверждение может истечь; тогда очередь ждёт нового подтверждения. FLAC-теги и обложки пока не записываются, а соответствие Apple↔Tidal может быть неточным.

- На 2026-10-07 Tailscale на роутере остановлен и исключён из автозапуска по просьбе владельца. Доступ к HomeNode и домашней сети через tailnet не работает; конфигурация и ключи Tailscale сохранены для возможного повторного включения. Это состояние роутера, а не изменение кода проекта.
- Стандартный облачный Telegram Bot API принимает отправку файла от бота до 50 МБ (скачивание ботом файлов ограничено 20 МБ). Отправка видео до 1 ГБ требует локального Bot API Server, который описан в SETUP, но не развернут; обычной отправкой через текущий бот это не работает.
- Если `ffprobe` недоступен или в файле нет тегов, исполнитель/альбом могут попасть в «Неизвестный исполнитель»/«Без альбома».
- Тесты кода проходят, но работа с реальным ботом и роутером должна быть проверена после развёртывания.
- На роутере у Transmission был ограничен виртуальный адресный объём примерно 71 МиБ (`mem_percentage=15`), что совпало с повторяющимися аварийными завершениями `std::bad_alloc`. После исправления лимит установлен на 25% памяти устройства; это снижает риск, но не исключает другие причины нехватки памяти.
- Функция импорта временная и может быть удалена отдельно; уже сохранённые музыкальные файлы при этом удаляться не должны.
- Импорт Windows не зависит от Telegram API ID/hash. Автоматическое получение файлов больше 20 МБ, присылаемых боту, по-прежнему ждёт развёртывания локального Bot API.
- Спящий или не обменивавшийся трафиком клиент без DHCP-аренды может не появиться до первого обращения к роутеру; пассивное обнаружение не является полным сканированием сети.
- Читалка сейчас поддерживает EPUB с растровыми изображениями; CBR/CBZ, PDF и отдельные папки изображений пока не поддерживаются. На диске найден один EPUB; служебный файл macOS `._…` отфильтрован.
