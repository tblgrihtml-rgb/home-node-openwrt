# Решения

## Временный импорт музыки через существующий бот

Дата: 2026-09-30.

Причина: нужно принять присланные владельцем аудиофайлы без отдельного приложения.

Варианты: загрузка через веб-форму; отдельный Telegram-клиент; существующий Bot API.

Выбран Bot API: он уже работает в HomeNode и проверяет владельца. Метаданные импортов хранятся в новой таблице SQLite, сами файлы — на SSD. Минус: ограничение скачивания 20 МБ. Если функция станет постоянной и будут нужны большие файлы, потребуется иной канал импорта; удаление функции не должно удалять музыку пользователя.
