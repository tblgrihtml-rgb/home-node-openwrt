# Журнал работ

## 2026-09-30 — Временный импорт музыки из Telegram

Что сделано: добавлен приём аудио/музыкальных документов только от привязанного владельца, ограничение 20 МБ, сортировка по тегам, защита путей, учёт дубликатов, меню `/music`, кнопки прослушивания и скачивания, скачивание музыки через сайт.

Изменённые части: `internal/telegram`, `internal/store`, `internal/server/media_stream.go`, `internal/webui/static`, `deploy/homenode.init`, README и `docs/`.

Проверка: `go test ./services/home-api/...`, `go vet ./services/home-api/...`, `node --check services/home-api/internal/webui/static/app.js`, `sh -n services/home-api/deploy/homenode.init`.

Риски: реальный импорт зависит от доступа Telegram через VPN, прав записи на SSD и лимита Bot API. Секреты и реальные аудиофайлы в Git не добавлялись.

После уточнения владельца выяснилось, что его файлы больше 20 МБ. Поэтому эту версию не развёртывали на роутере; дальнейший способ импорта требуется выбрать отдельно.

Следующий этап: выбран временный локальный Bot API на Mac и загрузка его файлов прямо на SSD роутера через SMB. Добавлена поддержка абсолютного пути `getFile` с проверкой разрешённого каталога и безопасным копированием/жёсткой ссылкой, а также скрипты запуска сервера и закрытого SSH-туннеля. Окончательное развёртывание ждёт Telegram API ID/API hash и проверки на реальном файле.

## 2026-09-30 — Перенос локальной музыки с Windows на SSD роутера

Что сделано: по SSH/SFTP прочитаны 911 поддерживаемых аудиофайлов из Windows-папки Music. Через Mac они записаны сразу на смонтированный SSD HomeNode. Каждый файл проверен после записи по размеру и SHA-256; 746 новых добавлены по каталогам исполнитель/альбом, 165 точных дублей пропущены. Исходные файлы Windows не удалялись и не изменялись. Удалены только созданные при этом переносе служебные файлы AppleDouble; два старых файла AppleDouble оставлены нетронутыми.

Изменённые части: `scripts/import-windows-music.py`, `docs/PROJECT_MAP.md`, `docs/SETUP.md`, `docs/PROJECT_STATE.md`, `docs/AI_WORKLOG.md`; также добавлены аудиофайлы вне Git в `/mnt/ssd/media/music`.

Проверка: дымовой импорт одного файла, затем полный импорт без ошибок; для одного FLAC отдельно сравнены SHA-256 на Windows и роутере (совпали). На роутере подсчитаны 1258 настоящих аудиофайлов, ноль `.part`, работающая служба HomeNode и 149,3 ГБ свободного места. Скрипт проверен `py_compile`.

Риски: совпадением считается идентичный файл целиком; разные кодировки/версии одной песни не удаляются. Для повторного запуска нужен доступ Mac к Windows SSH и смонтированному SMB-ресурсу HomeNode. Приватный SSH-ключ и музыка в Git не добавляются.
