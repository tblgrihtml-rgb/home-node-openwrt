## 2026-10-14 — Пробный перевод страницы манги на телефоне

Что сделано: в читалку добавлена кнопка перевода текущей страницы. По нажатию браузер загружает Tesseract.js с закреплённого jsDelivr URL (SRI для основного скрипта), подготавливает изображение страницы в уменьшенном canvas и распознаёт английский текст в одном Web Worker. Распознанный результат можно поправить, скопировать или открыть в Google Переводчике. Страница не уходит в OCR API; только текст страницы передаётся Google Translate при явном запуске.

Изменённые файлы: `services/home-api/internal/server/server.go`, `services/home-api/internal/webui/static/index.html`, `app.js`, `styles.css`, `sw.js`, `docs/DECISIONS.md`, `docs/PLAN.md`, `docs/PROJECT_MAP.md`, `docs/PROJECT_STATE.md`, `docs/SETUP.md`, `docs/SECURITY.md`.

Как проверить: в браузере телефона открыть HomeNode → «Манга» → книгу → «Перевести». При первом использовании дождаться загрузки OCR. Проверить, что распознанный текст появился и Google Переводчик открылся; если popup заблокирован, нажать кнопку открытия перевода в панели. Исправленный OCR-текст можно перевести повторно.

Проверка и развёртывание: `node --check`, `git diff --check` и сборка Linux ARM64 прошли. Новый бинарник установлен, служба HomeNode перезапущена без перезагрузки роутера; `/health` вернул `status: ok`, CSP содержит только нужные CDN-домены для загрузки OCR. Предыдущий бинарник сохранён на SSD в `/mnt/ssd/homenode/bin/homenode-api.pre-manga-ocr-20261014`.

Ограничения: iPhone/Safari ещё не проверен физически. OCR на телефонных процессорах может занять заметное время, особенно при первой загрузке модели; художественные буквы и звуковые эффекты могут распознаваться неверно. Перевод открывается в отдельной вкладке Google и передаёт туда только распознанный текст. Если popup/API сайта или CDN недоступны, панель всё равно оставляет текст доступным для копирования.
