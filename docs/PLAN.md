# План проекта

## Цель

Домашняя медиатека и управление загрузками на OpenWrt с доступом с телефона.

## Ближайшие задачи

### Видеоплеер с ambient-подсветкой

Статус: in progress — интерфейс и подсветка развёрнуты 2026-10-06; проверка iPhone/Safari и Tailscale ещё нужна.

Цель: улучшить просмотр аниме и фильмов, сохранив надёжность видео в браузере и на iPhone через Tailscale.

Этапы:

1. [Готово частично] Владелец выбрал мягкую динамическую подсветку по цветам кадра с фиолетовыми акцентами интерфейса; вид на компьютере проверен, iPhone ещё нет.
2. [Готово] Видео в тёмной области, действия сверху, серии сбоку на широком экране и под видео на телефоне; обратный отсчёт следующей серии находится поверх видео.
3. [Готово] Клиентская подсветка из уменьшенных кадров с выключателем, резервным статическим фоном, остановкой при паузе/скрытой вкладке и учётом уменьшения движения. Свободные области и симметричные чёрные полосы в самом файле закрываются цветом кадра; на ПК обновление каждые 100 мс, на телефоне — 180 мс.
4. [Готово] Штатные элементы `<video>` и существующие потоковые API, Safari-совместимый поток, HTTP Range, сохранение позиции и автопереход сохранены без изменения backend.
5. [Осталось] Проверить Safari на iPhone по LAN/Tailscale: MKV/MP4, перемотку, продолжение просмотра, следующую серию, полноэкранный и альбомный режимы, нагрузку и возможность отключить эффект.

Возможные файлы: `services/home-api/internal/webui/static/index.html`, `app.js`, `styles.css`, `sw.js`. Backend менять только если обнаружится отдельная проблема с потоком.

Риски: лишняя нагрузка на старых телефонах и различия браузеров; динамический эффект должен безопасно отключаться.

### Проверка импорта музыки на роутере

Статус: in progress.

После развёртывания проверить отправку нескольких небольших файлов боту, сортировку по тегам, повторную отправку, кнопки «Слушать»/«Скачать» и появление музыки на сайте. Возможные проблемы: права записи на SSD, доступ Telegram через VPN, отсутствие `ffprobe`.

Реальные музыкальные файлы владельца больше 20 МБ. Выбран локальный Bot API-сервер на Mac с файловым каталогом на SSD роутера; необходимы Telegram API ID/API hash и проверка доступности SMB/SSH перед переключением бота.

## Вопрос к владельцу

Получить Telegram API ID/API hash для локального сервера и проверить один большой файл перед массовой отправкой.

## Будущие улучшения

- Если временная функция станет постоянной, добавить импорт файлов крупнее лимита Bot API через защищённую веб-форму.
- Добавить поиск и плейлисты по музыке, если библиотека вырастет.
