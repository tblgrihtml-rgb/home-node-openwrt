# План проекта

## Цель

Домашняя медиатека и управление загрузками на OpenWrt с доступом с телефона.

## Ближайшие задачи

### Проверка импорта музыки на роутере

Статус: in progress.

После развёртывания проверить отправку нескольких небольших файлов боту, сортировку по тегам, повторную отправку, кнопки «Слушать»/«Скачать» и появление музыки на сайте. Возможные проблемы: права записи на SSD, доступ Telegram через VPN, отсутствие `ffprobe`.

Блокер для реальных музыкальных файлов владельца: они больше 20 МБ, а обычный Bot API не позволяет их скачать. Не развёртывать текущую версию как законченную функцию до выбора способа переноса больших файлов.

## Вопрос к владельцу

Для временного импорта крупных файлов выбрать локальный Telegram Bot API-сервер (потребуются Telegram API ID/API hash и компьютер, который будет работать во время импорта) либо перенос через SMB без отправки больших файлов боту.

## Будущие улучшения

- Если временная функция станет постоянной, добавить импорт файлов крупнее лимита Bot API через защищённую веб-форму.
- Добавить поиск и плейлисты по музыке, если библиотека вырастет.
