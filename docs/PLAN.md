# План проекта

## Цель

Домашняя медиатека и управление загрузками на OpenWrt с доступом с телефона.

## Ближайшие задачи

### Видеоплеер с ambient-подсветкой

Статус: planned — 2026-10-04 составлен план без изменений кода.

Цель: улучшить просмотр аниме и фильмов, сохранив надёжность видео в браузере и на iPhone через Tailscale.

Этапы:

1. Снять текущий вид плеера на широком экране и iPhone, когда HomeNode доступен; согласовать динамическую подсветку по цветам кадра или постоянную фиолетовую. Рекомендуется мягкая динамическая подсветка с фиолетовыми акцентами интерфейса.
2. Обновить компоновку окна: видео в тёмной области, заголовок и действия сверху, серии сбоку на широком экране и под видео на телефоне; обратный отсчёт следующей серии всегда виден.
3. Добавить клиентскую подсветку из уменьшенных кадров видео с ограниченной частотой обновления, выключателем и статическим запасным видом. Останавливать обновления при паузе/скрытой вкладке и учитывать системное уменьшение движения.
4. На первом этапе оставить штатные элементы `<video>` и существующие потоковые API, Safari-совместимый поток, HTTP Range, сохранение позиции и автопереход.
5. Проверить Chrome на Mac и Safari на iPhone по LAN/Tailscale: MKV/MP4, перемотку, продолжение просмотра, следующую серию, полноэкранный и альбомный режимы, нагрузку и возможность отключить эффект.

Возможные файлы: `services/home-api/internal/webui/static/index.html`, `app.js`, `styles.css`, `sw.js`. Backend менять только если обнаружится отдельная проблема с потоком.

Риски: лишняя нагрузка на старых телефонах и различия браузеров; динамический эффект должен безопасно отключаться.

### Проверка импорта музыки на роутере

Статус: in progress.

После развёртывания проверить отправку нескольких небольших файлов боту, сортировку по тегам, повторную отправку, кнопки «Слушать»/«Скачать» и появление музыки на сайте. Возможные проблемы: права записи на SSD, доступ Telegram через VPN, отсутствие `ffprobe`.

Реальные музыкальные файлы владельца больше 20 МБ. Выбран локальный Bot API-сервер на Mac с файловым каталогом на SSD роутера; необходимы Telegram API ID/API hash и проверка доступности SMB/SSH перед переключением бота.

## Вопрос к владельцу

Получить Telegram API ID/API hash для локального сервера и проверить один большой файл перед массовой отправкой.

## Будущие улучшения

- Добавить поиск и плейлисты по музыке, если библиотека вырастет.
