# План проекта

## Цель

Домашняя медиатека и управление загрузками на OpenWrt с доступом с телефона.

## Ближайшие задачи

### Вкладка и читалка манги

Статус: done, установлено на роутер 2026-10-14.

Добавлены каталог EPUB-книг, чтение в полноэкранном браузерном режиме, кнопки и жесты перелистывания, клавиатурные стрелки, переход по ползунку, направление справа налево, масштабирование по высоте/ширине, светлый/тёмный фон и сохранение позиции между устройствами. Поддерживается EPUB с растровыми изображениями. На роутере найденная книга успешно проиндексирована (2787 страниц), запрос первой страницы вернул JPEG. Визуальная проверка через браузер отложена: доступ к приостановленной вкладке HomeNode был запрещён политикой браузера; проверить отображение на iPhone/Safari можно при следующем удобном сеансе.

### Перевод одной страницы манги для чтения на английском

Статус: prototype развёрнут на роутер 2026-10-14; ожидает проверки на iPhone/Safari.

Кнопка запускает OCR только для текущей страницы в браузере телефона при помощи Tesseract.js, показывает распознанный текст для исправления и открывает Google Переводчик. На роутере не запускаются модели и не нужен ключ API; в Google передаётся распознанный текст, не изображение. Зависимость и английская OCR-модель загружаются с CDN при первом запуске. Следующий шаг — проверить скорость и точность на нескольких обычных страницах, работу popup/tab и кеширование библиотеки в Safari; если CDN недоступен, предложить пакетировать OCR-файлы локально.

### Видеоплеер с ambient-подсветкой

Статус: отменено по просьбе владельца 2026-10-06. После проверки подсветки возвращён прежний плеер. Не восстанавливать эффект без новой явной просьбы.

### Проверка импорта музыки на роутере

Статус: in progress.

После развёртывания проверить отправку нескольких небольших файлов боту, сортировку по тегам, повторную отправку, кнопки «Слушать»/«Скачать» и появление музыки на сайте. Возможные проблемы: права записи на SSD, доступ Telegram через VPN, отсутствие `ffprobe`.

Реальные музыкальные файлы владельца больше 20 МБ. Выбран локальный Bot API-сервер на Mac с файловым каталогом на SSD роутера; необходимы Telegram API ID/API hash и проверка доступности SMB/SSH перед переключением бота.

## Вопрос к владельцу

Получить Telegram API ID/API hash для локального сервера и проверить один большой файл перед массовой отправкой.
