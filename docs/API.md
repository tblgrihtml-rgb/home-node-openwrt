# API: изменение для музыки

## GET /api/media/stream?path=...&download=1

Возвращает исходный медиафайл как вложение (`Content-Disposition: attachment`) вместо встроенного воспроизведения. `path` — путь внутри настроенного медиакаталога. `download=1` необязателен; без него сохраняется прежнее потоковое поведение и HTTP Range.

Авторизация: обязательна сессия HomeNode. Ответ: 200/206 и байты файла. Ошибки: 400 при неверном пути, 404 если файл отсутствует, 401 без входа.

Импорт в Telegram обрабатывается Bot API long polling, отдельного публичного HTTP endpoint нет.

## Манга

### GET /api/manga

Возвращает EPUB-книги с изображениями в медиатеке, числом страниц, ссылкой на обложку и сохранённой страницей.

Авторизация: обязательна сессия HomeNode.

### GET /api/manga/page?path=...&page=...

Возвращает одну растровую страницу EPUB. `page` отсчитывается с нуля. Путь ограничен `.epub` внутри медиатеки; архивные записи больше 32 МиБ не выдаются.

Авторизация: обязательна сессия HomeNode.

### PUT /api/manga/progress

Сохраняет последнюю страницу. Body: `{"path":"...epub","page":0,"page_count":123}`. Требуется сессия и заголовок `X-HomeNode-Request: 1`.
