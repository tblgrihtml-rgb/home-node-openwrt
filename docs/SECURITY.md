# Безопасность

- Реальные токены, пароли, VPN-профили и ключи хранятся только в закрытом окружении, не в Git. `.env.example` содержит только пустые значения.
- Бот принимает музыкальные файлы исключительно в личном чате привязанного владельца. Доступ к веб-медиа требует авторизации HomeNode.
- Имена файлов очищаются, путь проверяется на выход из музыкального каталога, существующие отличающиеся файлы не перезаписываются. Облачный Bot API принимает от бота отправку до 50 МБ и скачивает файлы ботом до 20 МБ; локальный Bot API Server может принимать файлы до 2 ГБ и требует отдельного защищённого развёртывания.
- Не записывайте Bot API URL, токены, cookie или содержимое файлов в журналы.
- Перед публикацией проверяйте изменения и всю доступную историю Git на секреты и персональные адреса.
- Временный Bot API-сервер на Mac должен слушать только `127.0.0.1`; роутер обращается к нему через SSH reverse tunnel. API ID/hash остаются только в закрытом `.env` на Mac.
- `--files-dir` локального сервера размещается на подключённом SSD роутера, а не на системном диске Mac. Этот каталог может содержать исходные присланные файлы: не публикуйте его через интернет и не удаляйте до проверки медиатеки.
- При переносе музыки с Windows SSH должен быть доступен только в локальной сети. Приватный ключ Windows хранится вне Git; в репозиторий не добавляются адреса личных устройств, исходные аудиофайлы и временное окружение Python.
- Подтверждение музыкального источника хранится только в закрытом файле рядом с SQLite (`0600`), не в `.env.example`, коде или документации. Внешний источник допускает только callback на `127.0.0.1`; пользователь вручную вставляет полученный адрес в авторизованный HomeNode. Одноразовый `state` случайный, ограничен пятью минутами и используется один раз. URL с `grant` нельзя отправлять другим людям, записывать в журналы или хранить в браузерном интерфейсе после завершения.
- Браузер передаёт для новой музыкальной загрузки только числовой ID трека. Сервер сам получает метаданные и адрес файла, проверяет HTTPS и публичный IP каждой загрузки/редиректа, ограничивает размер 250 МиБ и принимает только FLAC. Это снижает риск SSRF и записи произвольных данных.
- Загрузчик должен видеть реальную точку монтирования SSD до создания временного файла. При отсутствии SSD нельзя писать во внутреннюю flash-память роутера. Временный файл и закрытая сессия источника никогда не публикуются через веб-медиатеку.
- SpotiFLAC Community — сторонний нестабильный источник. Проверяйте его условия и законность загрузки конкретного аудио. Функция не открывает доступ к музыкальной очереди без авторизации HomeNode.
